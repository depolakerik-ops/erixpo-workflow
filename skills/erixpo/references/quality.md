# Quality bar

No completion claim without fresh evidence. Run the command. Read the output.

Always: run `check:`, cover listed edge cases, write tests for what you just implemented (testing.md), self-review the diff, no secrets, update wiki when behaviour changed.

In-slice self-review is not stage-2 review. Stage 2 is a different session.
Dummy `check:` (`exit 0`) is a fail.
