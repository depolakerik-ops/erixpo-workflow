# Craft — this must not feel cheap

Cheap is process theater: empty wiki pages, keyword routing as intelligence, “I searched Linear Notion Things” without opening them, a factory worker prompt, a CSS card pretending to be iOS, a README that says “Welcome to your new app.”

Good is a specialist who already knows this folder, looks at real work in this field, and ships something a picky human would keep.

## Talk

- Do not narrate the workflow. Do not say which SKILL.md you are following.
- One line of what you understood. Then do it (or one question).
- Product language, not factory language, in anything the human reads (README, UI copy, chat).

## Research (when building)

Cheap: a list of names. Good: **opened** sources.

Each comparable / docs hit in `.erixpo/research.md`:

```
- opened: https://… — one sentence you actually learned
```

If the host cannot fetch, write `could not open:` and what you tried. Do not fake it.

Steal structure for **this field**. A SwiftUI app does not get a SaaS landing page as its reference.

## Docs

- No empty `ARCHITECTURE.md`, no blank token tables, no `{{PRODUCT}}` left in HTML.
- Wiki pages exist because something is true, not because a template had a slot.
- `documents/ui/` is filled with real numbers in the same slice you first draw pixels. Blank tables are not a design system.

## UI

The tutorial default for **this surface** is a fail ([slop.md](slop.md)). HTML mockups are web-only. Native uses the platform, not a 720px card.

## Code

Would you keep this file if a respected person reviewed it? If not, it is not done. Tests that can fail. Check that ran. No extras they did not ask for.

## Chat

If you need to mention process, one clause max. The work is the product, not erixpo.
