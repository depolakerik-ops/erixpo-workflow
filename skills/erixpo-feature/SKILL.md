# erixpo feature

Do not restart the whole product interview.

Ask who it is for, must-have behaviour, what it must not break. If visible, propose 2 UI directions (ui.md). Narrow research if the feature needs new infra or a new test/UI tool.

Plan: slices, edge cases, tests to add (testing.md), optional extras.
Build like auto: implement → tests for that change → self-review → check → wiki.
