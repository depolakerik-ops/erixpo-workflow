# erixpo workflow

Adaptive autonomous workflow. One command. Any agent. Any kind of work in a repo.

You talk. The agent classifies the repo and the request (software, site, automation, research, writing, ops, assistant), then does the work against a real check. Progress and memory live on disk.

## Install

```bash
git clone https://github.com/depolakerik-ops/erixpo-workflow /tmp/erixpo-workflow
bash /tmp/erixpo-workflow/install.sh
```

Then `/erixpo`.

## Tracks

`/erixpo` routes: init, learn, work, fix, feature, review, auto, new, docs.

## Self-improvement

`.erixpo/PROFILE.md`, `MEMORY.md`, `USER.md`, `learnings.jsonl`, and `.erixpo/skills/`.
